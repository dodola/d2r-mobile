# D2R Mobile 1.2.8-beta.1-94012（2026-10-28）

English: [CHANGELOG_1.2.8-beta.1-94012_2026-10-28.md](CHANGELOG_1.2.8-beta.1-94012_2026-10-28.md)

基于 1.2.7-94012 的 Android beta 更新，版本号升为 14。使用正式包名 `org.d2r.mobile`、原发布证书和不可调试构建，可覆盖升级已有同包名/同签名版本。首次安装继续使用原 `D2R-Offline-94012.d2rpack`；已经导入 94012 数据的用户只需升级 APK。

## 新增

- 自定义页新增原版、肩后、第一人称三档镜头，默认原版，点击应用后切换。
- 新镜头支持右侧空白拖动俯仰、第一人称水平转向、转向按钮、地图方向箭头和屏外怪物提示；同步转换摇杆、点按、名称及血条位置。
- Adreno 750–799 默认在运行时内联包含 subgroup helper 的着色器，升级 APK 即可使用既有离线资源；其它机型沿用原有默认策略。

## 修复与行为调整

- 全屏地图选择在关闭面板、换区域后恢复，不改写玩家地图配置；剧情过场后恢复小地图。
- 修复按 + 关闭加宽仓库后，背包位置逐次向右漂移。
- 清理退出页面后的手柄提示，并限制提示条最多八项。
- 普通需求管线等待编译完成后再绘制，避免冷编译预算耗尽时省略对象；后台预热保留，首次遇到新效果仍可能停顿。
- 增加按驱动、着色器配置和完整管线状态隔离的失败记录，支持明确诊断及恢复；默认不静默跳过隔离管线。

## 离线安装与兼容

- 包名 `org.d2r.mobile`；`versionCode=14`；`versionName=1.2.8-beta.1-94012`；发布证书保持不变。
- 沿用 94012 离线资源包、内置 Turnip、六个可选 MOD 包及已有存档管理功能。
- 更新时覆盖安装，无需卸载或重新导入匹配的 94012 数据。新装时先安装 APK，再在启动器选择 `.d2rpack`。
- APK 的 `debuggable=false`。游戏内可选 Debug 功能与 Android 可调试标志是两个独立设置，既有功能继续保留。

## 验证与 beta 限制

新增十组 CPU 回归通过；实际本地资源包的 6,929 个着色器中，187 个 helper 模块全部内联及校验成功。Honor TNA_AN00 / Adreno 642L 的真实库设置检查 188 项、纹理视图检查 6,201 项，以及合成着色器真实 Vulkan 派发通过。原生构建、完整 APK 签名、16 KiB 对齐和载荷校验通过，资源包逐文件及整包哈希另外复核。

尚未在 Adreno 750、Mali 或完整游戏流程中完成本次新镜头验收；所有区域、战斗、过场、传感器操作及长时间运行仍需测试。1.2.7 中已记录的角色中文改名卡死、部分设备后台 surface lost，以及部分 Debug/MOD 功能的验收限制仍适用。本版明确作为 beta 提供，不把 CPU/合成设备探针视为完整游戏画面验证。

实现和详细证据见 [上游移植记录](UPSTREAM_ANDROID_PORT_2026-10-28.zh-CN.md)。交付目录的 `build-report.json`、`source-provenance.json`、`release-verification.json` 和 `SHA256SUMS.txt` 记录本次实际构建及校验结果。
