# Android 兼容性与性能持续优化

目标：结合现有 NVN 后端、已审阅的 X1-BOX、ZeldaWWHDRecomp 以及其他本地参考，
提高真实游戏的驱动兼容性、画面正确性、启动与运行性能。保持 main 和现有平台边界。
参考实现只作为设计依据，不直接移植不匹配的 GX2/Latte 或其他授权的代码。

验收必须区分策略单测、实际后端 GPU 读回、完整游戏和实际显示时间戳。
每个性能结论应有同设备、同场景、同配置的对照；不能以夹具耗时代替游戏 FPS。

## 工作范围与当前状态

- [ ] 驱动能力协商：API/扩展/feature 查询合法性、采样器限制、格式与用途支持。
- [x] 跨启动管线缓存：设备/驱动/策略/feature 身份、受限读取、完整性校验、原子写入、
      坏缓存重建、后台保存、冷启动/热启动对照。
- [ ] Shader 正确性：保留 Qualcomm ballot/蒙皮修复，建立系统/兼容驱动回归记录；
      对新增问题用最小 Shader 与实际资源读回定位，禁止跳过绘制掩盖错误。
- [ ] 纹理、顶点与同步：审计格式 fallback、过滤与顶点读取边界；保留已有 BC 解码；
      根据实际读写关系优化同步，不能直接全局收窄屏障。
- [ ] CPU 与 GPU 性能：定位编译、描述符、资源上传、提交和 present 的主要耗时，
      对已有优化做同场景对照，只有正确性通过且收益可重复才更改默认值。
- [ ] 驱动生命周期：选项、加载、窗口重建、故障恢复与缓存隔离；恢复不能替代系统驱动修复。
- [ ] 交付：可复现验证入口、原始结果和准确的范围限制；生成可追溯构建，完整游戏验证。

## 本轮发现（2026-10-16）

基线 main `62faf1e` 干净。已有 `NvnVkGpuProfile`、`NvnVkQuirkRegistry` 和缓存身份，
但 VkPipelineCache 没有磁盘持久化。采样器直接使用 guest 各向异性参数，未检查 feature/limit。
DriverProperties 在 Vulkan 1.1 上无条件查询，需要按核心版本或扩展支持门控。

实际连接设备：`A6BFUT1C07005372`，TNA-AN00，Android 14，系统报告 Adreno 642L。
不同于旧记录的 Adreno 830/640，旧测试结果不能作为这台设备的验收证据。
设备已有游戏进程与资源，先用独立夹具验证，保留资源、存档和用户设置。

已完成第一批能力协商、格式属性缓存、采样降级和持久化缓存，并完成本机系统驱动
夹具与真实角色选择启动验证。详见
[本轮记录](ANDROID_COMPAT_PERFORMANCE_2026-10-16.zh-CN.md)。这不是整个目标完成：
驱动矩阵、实际显示帧时间、营地/战斗对照、CPU/GPU 主瓶颈优化及故障恢复仍需继续。

第二批修正了写死的提交模式/PSO hash 日志及 ADPF 对 submission 条件等待的计时，
新增只读的实际呈现采集入口，完成四种 CPU 缓存组合的系统驱动 GPU 读回与六轮菜单对照。
状态缓存减少约 67% 状态命令，但尚无显著、普遍 FPS 收益证据，故保留实验开关。
菜单 GPU chunk 时间约 51 ms/帧，继续定位具体 GPU Pass；详细结果见
[CPU/GPU 诊断与对照](ANDROID_CPU_GPU_PROFILE_2026-10-16.zh-CN.md)。
实际呈现采集已有本机证据，营地/战斗和跨设备验收仍未完成，总目标保持进行中。

第三批关联了 HDR 颜色目标与两个主要片元 Shader，并完成实际安装版本的四轮
SPIR-V 优化候选对照；未测出收益，已恢复原始文件。普通运行的逐次复制日志改为
窗口聚合，45 秒菜单区间日志量减少约 80%。系统驱动下新增已核对玩家/区域的
60 秒营地采集（16.511 FPS）和短距离摇杆移动验证；战斗、长期和跨设备验收仍未完成。
完整记录见 [HDR 与营地验证](ANDROID_HDR_CAMP_VALIDATION_2026-10-16.zh-CN.md)。

第四批补齐 GPU 驻留的 2D 深度／模板纹理最近邻缩放：优先原生 blit，缺失时用
深度写入和八次 stencil 位掩码绘制；组合格式 CPU 读回改为分 aspect 后重组。
本机系统驱动四种深度格式均缺少 blit，已实际触发自动绘制回退。四种配置共 144 案例、
552,960 个深度／模板 texel 通过独立预期检查，包含局部/mip/数组层保留、guest 绑定恢复
和遮挡计数；跨配置读回逐字节一致。更新应用后系统驱动营地 60 秒为 17.294 FPS，
仅作回归，不归因为提速；本营地没有触发深度缩放，不能代替新增功能的夹具证据。
原生深度 blit、顶点格式、战斗/长期、跨设备及主要 GPU 性能优化仍待继续。
详情见 [深度／模板复制验证](ANDROID_DEPTH_COPY_VALIDATION_2026-10-16.zh-CN.md)。

第五批分离顶点与纹理格式策略，补齐 79 种已验证顶点格式的获取、RGB 拆分、scaled 整数转换，
从 SPIR-V 反射接口并缓存适配模块，将策略纳入 PSO 身份、Shader ABI 升至 2。
数组/实例范围增加末尾边界和对齐检查，索引可能由 GPU 生成，完整索引获取边界仍待实现。
系统驱动四种配置共 5,056 个案例、20,709,376 字节读回一致，18 个实际适配模块通过 IR 校验，
三个短范围输入被正确拒绝；实际游戏 25 个顶点 Shader 的 75 个适配结果通过 IR 校验。
覆盖安装后角色选择、营地及短距离移动无明显拉伸；营地 60 秒实际呈现 16.752 FPS，
不据此宣称提速或回退。普通 RGB 在本机有原生支持，拆分由测试强制；自然路径验证 scaled 转换。
详情见 [顶点输入验证](ANDROID_VERTEX_INPUT_VALIDATION_2026-10-16.zh-CN.md)。整个兼容性与性能目标继续进行。

第六批补齐同进程分块提交诊断与 GPU 生产者正确性检查：缓存开/关共 9,600 draw、
48 次 Compute、524,288 字节读回一致。营地 11 轮交错实测中，阈值 16、256 均无
稳定收益，保留默认 48；关闭中途提交的一次样本降到 13.840 FPS，恢复后约 16.96 FPS。
独立营地计时将最重 HDR 组定位为约 15.444 ms/帧，包含边界同步，不能视为纯 Shader 时间。
普通模式恢复后 60 秒实际呈现 16.583 FPS；不宣称本批提速。诊断标记已移除，数据保留。
详情见 [分块提交与营地 GPU 计时](ANDROID_SUBMISSION_TUNING_2026-10-16.zh-CN.md)。
继续围绕实际重型 Pass、跨设备及战斗/长期验证推进完整目标。

第七批增加默认关闭、按 feature 协商且按最终 Fence 收集的 Pass 管线统计。
五种系统驱动配置共 24,000 次绘制、120 次 Compute、1,310,720 字节读回一致，
并验证查询容量耗尽只省略统计、不省略绘制，跨 chunk 与最终提交复用计数正确。
营地最重 HDR 组在排除管线创建窗口后，片元调用约 188 万/帧、两个 Pass，
约为目标像素数的 2.043 倍。两个主片元 Shader 强制 EarlyFragmentTests 的独立候选
没有有意义的调用量减少或性能收益证据，不加入默认路径；原始资源恢复。
详细范围、原始记录和诊断开销见 [片元统计与 HDR 调查](ANDROID_FRAGMENT_STATISTICS_2026-10-16.zh-CN.md)。
继续调查实际 Shader/资源瓶颈，以及 GPU 索引边界、驱动生命周期、战斗/长期与跨设备验收。

第八批补齐已支持的 `fullDrawIndexUint32` 逻辑设备 feature，将其加入缓存身份。
系统驱动两种命令缓存状态共 5,376 次索引绘制、42 次 Compute、2,752,512 字节目标读回一致，
覆盖 CPU／GPU 索引来源、16／32 位、24／31 位边界、最高 32 位索引、负 base vertex、
零 stride，以及阈值 0／16／48 的实际提前提交。
规范审计否定“基础 robustness＋pSizes 即可完整隔离子范围”的假设；没有启用该不充分方案。
完整 GPU 索引顶点边界、缺失 feature 的设备回退和实际性能主瓶颈仍待继续。
覆盖安装后系统驱动营地 60 秒实测 16.583 FPS，16 个窗口无管线创建；仅作回归，不声称提速。
UID、ROMFS 与 15 个存档／设置文件保留，原始 Shader 与普通运行模式均核对。
详见 [完整索引能力与验证](ANDROID_INDEX_CAPABILITY_2026-10-16.zh-CN.md)。

第九批根据真实 CPU 采样，跨提交保留每槽不可变 ImageView/RenderPass/Framebuffer，
在真实 Fence 完成后复用或按阈值回收，纹理销毁前 drain 并清除引用。
两种命令缓存状态新增 748 draw、12,255,232 字节独立预期读回通过。
同进程六轮有效营地对照中位数 17.860 → 19.286 FPS（+7.98%）；
默认开启版本覆盖安装后普通模式 60 秒为 19.324 FPS，实际映射库/UID/资源/存档均核对。
管线创建干扰样本保留并排除；仍未达到 30 FPS，继续优化剩余 CPU/GPU 热点。
详见 [跨提交附件对象复用](ANDROID_RESOURCE_RETENTION_2026-10-16.zh-CN.md)。
