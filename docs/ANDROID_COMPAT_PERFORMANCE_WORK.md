# Android 兼容性与性能持续优化

目标：结合现有 NVN 后端、已审阅的 X1-BOX、ZeldaWWHDRecomp 以及其他本地参考，
提高真实游戏的驱动兼容性、画面正确性、启动与运行性能。保持 main 和现有平台边界。
参考实现只作为设计依据，不直接移植不匹配的 GX2/Latte 或其他授权的代码。

验收必须区分策略单测、实际后端 GPU 读回、完整游戏和实际显示时间戳。
每个性能结论应有同设备、同场景、同配置的对照；不能以夹具耗时代替游戏 FPS。

## 工作范围与当前状态

- [ ] 驱动能力协商：API/扩展/feature 查询合法性、采样器限制、格式与用途支持。
- [x] 跨启动管线缓存：设备/驱动/策略/feature 身份、受限读取、完整性校验、原子写入、
      坏缓存重建、后台保存、冷启动/热启动对照。
- [ ] Shader 正确性：保留 Qualcomm ballot/蒙皮修复，建立系统/兼容驱动回归记录；
      对新增问题用最小 Shader 与实际资源读回定位，禁止跳过绘制掩盖错误。
- [ ] 纹理、顶点与同步：审计格式 fallback、过滤与顶点读取边界；保留已有 BC 解码；
      根据实际读写关系优化同步，不能直接全局收窄屏障。
- [ ] CPU 与 GPU 性能：定位编译、描述符、资源上传、提交和 present 的主要耗时，
      对已有优化做同场景对照，只有正确性通过且收益可重复才更改默认值。
- [ ] 驱动生命周期：选项、加载、窗口重建、故障恢复与缓存隔离；恢复不能替代系统驱动修复。
- [ ] 交付：可复现验证入口、原始结果和准确的范围限制；生成可追溯构建，完整游戏验证。

## 本轮发现（2026-10-16）

基线 main `62faf1e` 干净。已有 `NvnVkGpuProfile`、`NvnVkQuirkRegistry` 和缓存身份，
但 VkPipelineCache 没有磁盘持久化。采样器直接使用 guest 各向异性参数，未检查 feature/limit。
DriverProperties 在 Vulkan 1.1 上无条件查询，需要按核心版本或扩展支持门控。

实际连接设备：`A6BFUT1C07005372`，TNA-AN00，Android 14，系统报告 Adreno 642L。
不同于旧记录的 Adreno 830/640，旧测试结果不能作为这台设备的验收证据。
设备已有游戏进程与资源，先用独立夹具验证，保留资源、存档和用户设置。

已完成第一批能力协商、格式属性缓存、采样降级和持久化缓存，并完成本机系统驱动
夹具与真实角色选择启动验证。详见
[本轮记录](ANDROID_COMPAT_PERFORMANCE_2026-10-16.zh-CN.md)。这不是整个目标完成：
驱动矩阵、实际显示帧时间、营地/战斗对照、CPU/GPU 主瓶颈优化及故障恢复仍需继续。

第二批修正了写死的提交模式/PSO hash 日志及 ADPF 对 submission 条件等待的计时，
新增只读的实际呈现采集入口，完成四种 CPU 缓存组合的系统驱动 GPU 读回与六轮菜单对照。
状态缓存减少约 67% 状态命令，但尚无显著、普遍 FPS 收益证据，故保留实验开关。
菜单 GPU chunk 时间约 51 ms/帧，继续定位具体 GPU Pass；详细结果见
[CPU/GPU 诊断与对照](ANDROID_CPU_GPU_PROFILE_2026-10-16.zh-CN.md)。
实际呈现采集已有本机证据，营地/战斗和跨设备验收仍未完成，总目标保持进行中。

第三批关联了 HDR 颜色目标与两个主要片元 Shader，并完成实际安装版本的四轮
SPIR-V 优化候选对照；未测出收益，已恢复原始文件。普通运行的逐次复制日志改为
窗口聚合，45 秒菜单区间日志量减少约 80%。系统驱动下新增已核对玩家/区域的
60 秒营地采集（16.511 FPS）和短距离摇杆移动验证；战斗、长期和跨设备验收仍未完成。
完整记录见 [HDR 与营地验证](ANDROID_HDR_CAMP_VALIDATION_2026-10-16.zh-CN.md)。

第四批补齐 GPU 驻留的 2D 深度／模板纹理最近邻缩放：优先原生 blit，缺失时用
深度写入和八次 stencil 位掩码绘制；组合格式 CPU 读回改为分 aspect 后重组。
本机系统驱动四种深度格式均缺少 blit，已实际触发自动绘制回退。四种配置共 144 案例、
552,960 个深度／模板 texel 通过独立预期检查，包含局部/mip/数组层保留、guest 绑定恢复
和遮挡计数；跨配置读回逐字节一致。更新应用后系统驱动营地 60 秒为 17.294 FPS，
仅作回归，不归因为提速；本营地没有触发深度缩放，不能代替新增功能的夹具证据。
原生深度 blit、顶点格式、战斗/长期、跨设备及主要 GPU 性能优化仍待继续。
详情见 [深度／模板复制验证](ANDROID_DEPTH_COPY_VALIDATION_2026-10-16.zh-CN.md)。
