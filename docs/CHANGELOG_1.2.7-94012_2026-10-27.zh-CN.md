# D2R Mobile 1.2.7-94012 更新日志（2026-10-27）

相对上一个正式发布版 1.1.2-94012（versionCode 5）的累计变更，合并了 1.2.0 – 1.2.7 的内部版本。适用游戏版本 94012；包名 `org.d2r.mobile`；versionCode 13；与之前的发布版同一签名证书，可直接覆盖安装，存档不受影响。

## 重要修复
- **开启 Debug 后，存档导入/导出/备份操作的是正式存档**：游戏此时读的是独立的 Debug 存档，导入后看不到角色。现在启动器随 Debug 开关选择存档目录：Debug 为 `debug/save`，MOD + Debug 为 `mods/<id>/debug-save`；预览中显示“Debug · …”。正式与 Debug 存档的 ZIP 可互相导入。
- **进入第五幕必定闪退**：渲染层同时驻留的纹理上限为 4096，第五幕场景（如哈洛加斯）的纹理数超过后会直接中止（日志 `STOP texture target/layers/MSAA`）。纹理上限提高到 16384；着色器与采样器上限不变。
- **NPC 对白无声（语音丢失）**：游戏以 48 kHz / PCM16 / 6 声道输出，NPC 对白在中置声道，手机双声道输出收不到。现在 Android 在 AAudio 回调里把 6 声道按 5.1 规则下混为双声道（中置与同侧环绕合入左右声道、预留余量并限幅，不混入低频声道），实际声卡以双声道打开；游戏仍看到 6 声道。已在 PPG 上与卡夏交谈，语音听感确认恢复。
- **NPC 菜单按键同时触发原始触屏输入**：导航圆钮的手指原先被标成“无类别”，会再被转发为原始触屏，可能干扰对话。现在保留目标类别，只抑制持续按住的按键。
- **宽屏设备两侧黑边 / 比例不对**：游戏输出现在按实际窗口比例生成（掌机档保持 720 高、主机档保持 900 高，宽度取最近的 8 像素倍数），不再固定 16:9。PPG 由 1280×720 变为 1592×720。虚拟按键、佣兵栏、小地图按刘海/挖孔安全区避让，横屏正反方向均适配。窄于 16:9 的窗口仍等比居中。
- **选择与当前资源不匹配的 MOD 导致启动闪退**：启动器不再列出不匹配的包；底层校验失败时停止启动并显示明确错误，保留选择，不挂载存档，不再直接中止。
- **局内点击被虚拟手柄层吞掉**：新增触摸入口优先处理，使局内 DEBUG 按钮与调试页面可点击。
- **MOD 目录经系统别名路径时误报“游戏文件准备失败”**：读取描述文件前规范化路径。
- 后台切换时 Surface 暂时消失，保留最后有效窗口尺寸，避免新建线程回退到 16:9 参数。

## 新增

### 启动器（1.2.0 / 1.2.1）
- 统一的设置页：渲染比例、FPS 显示、图形驱动、MOD 选择、Debug 开关。
- 存档传输：ZIP 导出/导入，**也可直接选择单个 `.d2s` 角色文件导入**（见下），导入前预览范围，支持合并导入、可恢复的提交、自动备份与备份导出；开始游戏按钮在横竖屏下始终可见。
- 界面重绘：原创静态拱门场景、统一卡片/图标/开关/对话框样式，涟漪与焦点状态。

### 直接导入 .d2s 角色文件
- “导入存档”除 ZIP 外可直接选择 `.d2s`（例如从 PC 复制的角色）。会校验文件头：魔数、版本 `0x69`、长度和校验和，不合格时拒绝导入。
- 自动放成 `<角色名>/<角色名>.d2s` 并生成 `.d2s.meta`，之后与 ZIP 相同：预览、确认、导入前自动备份、可回滚。
- 角色名限制：游戏不接受中文等字符的角色名（会弹出“请重新命名”，当前版本改名后会卡死）。因此导入时自动整理名字：只保留英文字母和一个中间下划线（连字符变下划线），其余去掉；去掉后不足 2 个字母（如全中文名）则改用职业名（`Sorceress`、`Paladin`…）。重名时在末尾加字母，不覆盖已有角色。名字改动会同步重算文件校验和。

### Debug 调试工作台（可选）
- 启动器设置、游戏内“选项 → 自定义”都有“Debug”开关，**下次启动**生效，运行中不切换存档。
- 开启后主界面左侧出现 **DEBUG** 按钮，点击进入独立全屏调试页面，按钮已加大，适合触摸。
- Debug 使用**独立存档**，不会改动正式角色：
  - 正式：`files/d2r-mobile/save`
  - Debug：`files/d2r-mobile/debug/save`
  - MOD：`files/d2r-mobile/mods/<id>/save`；MOD + Debug：`mods/<id>/debug-save`
- 调试页面分类：暗金装备、套装装备、符文、宝石、武器底材、护甲底材、药水与杂物、场景跳转、调试工具。
  - 暗金/套装可按“全部 / 武器 / 护甲 / 饰品”筛选。
  - 选中条目后点“放到地面”，物品**直接掉在角色脚边**，不占背包；暗金/套装由原版服务端生成器生成，带真实随机属性，并已辨识。
  - 场景跳转：覆盖五幕共 132 个区域，按幕切换，名称后附区域编号；第五幕需要资料片。
  - 调试工具：恢复生命与法力、**金币 +100,000**（每点一次）、**技能点 +10**、**属性点 +100**、揭示当前地图。
- 界面重新设计：标题栏、面板边框、选中高亮、暗金（金色）/套装（绿色）名称配色。

### 调试商店（实时）
- 开启 Debug 后，游戏内所有商人的商品价格降为 **1 金币**（药水、武器、护甲等），并加入固定库存：符文 1–33、完美宝石、传送门卷册、珠宝、钥匙等。
- 直接修改已加载的物品表，无需安装 MOD；商人库存在新进游戏时刷新。

### 可选 MOD（启动器中选择）
- 商店 MOD：符文 1–33、完美宝石、恢复药、传送门卷册、珠宝、钥匙等进入阿卡拉/德罗南/奥米斯/杰米拉/玛拉商店。
- 符文之语 MOD：武器类扩展到全部武器、圣骑士盾扩展到盾牌、可解除非天梯限制。
- 调试全套 MOD：以上合并。
- 共 6 个包（含物品注释版本）。

## 已移除
- Debug 中的“符文之语生成”（调试页面和命令）已移除。符文之语 **MOD** 不受影响。

## 已知问题与限制
- 游戏内给含中文等字符的角色改名后会卡死（日志停在创建新角色文件之后），尚未定位；导入 d2s 时已自动改成合法名字以避开。
- 切到后台后个别设备可能出现 surface lost（`STOP swapchain acquisition`）导致退出，本版未改动渲染生命周期。
- Debug 页面中的部分新增提示仍为中文硬编码，其他语言未补齐。
- 以下内容发布前未做完整实机验收：金币超过“等级×10000”携带上限后的行为、落地物品的显示、套装生成、MOD 启动与商店购买流程、武器/护甲/饰品筛选。
- NPC 语音只确认了卡夏对话；长按确认、返回穿透、全部暂停恢复场景未单独回归。运行中改变窗口长宽比（分屏/折叠）未验收。
- 离线数据包 `D2R-Offline-94012.d2rpack` 沿用上一版（本次未改动），首次安装仍需先导入。
