# Android 1.1.0 · 94012 离线安装版

日期：2026-10-20。应用版本：`1.1.0-94012-launcher`，versionCode `2`，包名 `org.d2r.mobile`。
代码来源：`main@4d95a686272ba9624f870938b3bd11abfc09cd14`；支持 Android 10+ / arm64-v8a，需满足 Vulkan 功能要求。

## 相对上一版的功能更新

本版说明覆盖 10 月 18–20 日主线更新，相对此前 91738 离线版：

- 支持「术士君临」资料片与 94012 配套离线安装。
- 完善触屏操控、技能栏和 HUD、面板操作；扩展手柄输入，硬件兼容仍待验证。
- 新增自动/均衡画质档，优化性能、画面显示与驱动兼容。
- 完善后台存档与恢复、错误反馈。
- 新版启动器：状态更直观，导入可确认停止，重试复用已校验文件。
- 新增适配 MOD 加载、独立存档和当前地图一键全开。

完整前后对照及提交依据见[三天更新核对](ANDROID_UPDATE_REVIEW_2026-10-18_20.zh-CN.md)。
此前已经存在的摇杆、离线安装和原画质/性能档不重复包装成首次新增。

## 性能与稳定性实现记录

默认启用 mip/layer 上传批处理和解排布工作区复用，减少逐子资源分配与提交；缩小剩余资源规划数组的清零范围。
保留深度/模板分面、复制区域对齐与整数溢出检查。修复设置确认框的输入优先级，并检查 Android Vulkan 构建定义。

原生 BC 压缩直传、线程让出退避均属默认关闭的实验选项，不能将其描述为标准版已启用的收益。
细节和可回退开关见[移植记录](ANDROID_INTEGRATION_PORT_2026-10-20.zh-CN.md)。

启动器保留进程内导入状态，区分选择、导入、提交、就绪与错误；取消须确认，提交阶段不可取消。
重试时复用已校验文件；系统回收进程后需重新选择原包。驱动设置保存失败会回退，失效 MOD 选择可修复。
资源就绪后由用户点击启动，详情见[启动器说明](ANDROID_LAUNCHER_2026-10-20.zh-CN.md)。

支持准备好的版本匹配 MOD 包、独立存档目录和当前地图展开；PC 版 MOD 需要转换、校验和功能适配，
见[MOD 文档](ANDROID_MODS_2026-10-20.zh-CN.md)。标准离线安装版未编入 QA 控制台；
开发者可按[调试模式文档](ANDROID_DEBUG_MODE_2026-10-20.zh-CN.md)另行构建。

## 离线安装

同一交付目录包含：

| 文件 | 用途 |
| --- | --- |
| `D2R-Mobile.apk` | 不可调试、发布签名的应用安装包 |
| `D2R-Offline-94012.d2rpack` | 94012 离线资源包，9,246,256,002 字节 |
| `安装说明.txt` | 首次安装、覆盖升级、驱动和故障处理 |
| `SHA256SUMS.txt` | 成套文件的 SHA-256 |
| `offline-manifest.json` / `offline-pack-build.json` / `build-report.json` | 输入、构建和校验记录 |

1. 首次安装准备约 20 GB 空间；已下载资源包时，导入还需额外约 9.5 GB。
2. 安装 APK，打开 D2R Mobile，选择匹配的 `.d2rpack`，无需解压。
3. 等待导入和校验完成，点击“启动游戏”。之后可删除下载目录中的资源包。
4. 更新时覆盖安装；不要卸载，否则会删除应用内部数据和存档。旧 91738 资源不能与本版混用。

构建脚本与输入要求见[APK 文档](ANDROID_D2R_APK.md)。游戏内容由使用者自行准备；
本说明不提供公共资源包下载地址。
